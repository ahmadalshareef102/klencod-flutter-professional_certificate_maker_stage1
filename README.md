# Professional Certificate Maker – Stage 1

هذه حزمة تأسيسية للمرحلة الأولى من مشروع صانع الشهادات الاحترافي.

## المتطلبات
- Flutter SDK متوافق مع Dart 3.4 أو أحدث.
- Android SDK.
- بيئة بناء Android مناسبة.

## التشغيل
```bash
flutter pub get
flutter analyze
flutter run
```

## البناء
```bash
flutter build apk --release
```

## حالة المرحلة الأولى
تم إنشاء:
- هيكل المشروع الأساسي.
- ثيم عربي RTL.
- لوحة رئيسية أولية.
- شاشات أولية للقوالب والمشاريع والمؤسسات.
- شاشة نموذج أولي للمحرر.

لم يتم بعد تنفيذ:
- قاعدة البيانات الفعلية.
- محرك التصميم الحر.
- حفظ المشاريع.
- التصدير والطباعة.
- القوالب الفعلية القابلة للتحرير.

هذه العناصر مراحل لاحقة وليست وظائف مكتملة في هذه الحزمة.
